# Gallery artwork

All SVG illustrations in this directory were drawn for the ALNILAM Demo field atlas by the ALNILAM contributors on 2026-11-23. They are original vector artwork, contain no embedded third-party media or fonts, and are distributed under the repository's Apache-2.0 license. Each `*-thumb.svg` is a separately authored, compact preview; the corresponding un-suffixed file is the full-size original.
