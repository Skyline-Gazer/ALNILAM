## Native execution and authority

Actual isolated private repository: [KoolingMachine/ads-cnb-acceptance-20261027](https://cnb.cool/KoolingMachine/ads-cnb-acceptance-20261027). The current browser is authenticated as pony-gazing. Source checkout, native PR, branch protection, scanner/review execution and artifact download must each be read back independently. A GitHub green check is not a CNB result.

`pull_request` already includes source updates. SCA publication uses the trusted `pull_request.target` event, `scanMode: diff`, supported `format` and `publish: true`. The official code-review plugin documents ordinary PR events separately; it writes the actual `status/issues` schema, and critical findings can coexist with exit zero. There is one deterministic severity gate. It loads verifier code from the trusted target, rejects unknown/missing findings and source/target movement, and verifies the evaluated merge checkout. Native protection must prevent a PR from replacing its own authoritative pipeline; source code alone cannot prove that protection. Fork PRs fail closed pending a trusted API adapter. No PR-authored warning exception is accepted.

All container references in `.cnb.yml` use observed immutable registry digests. The Playwright manifest list includes amd64 and arm64; the runner explicitly selects amd64. Registry availability is not proof of a CNB pull/launch. Image source, manifest and runtime are recorded separately.

## Measurements and failure evidence

The Node source-only LCOV excludes tests/generated code and covers imported application/composition modules; it does not cover Astro subprocesses, Svelte UI or browser execution. The local baseline was 359/462 lines (77.7056%); 77% is provisional until native confirmation. Native incremental coverage requires changed application lines; a no-source-diff result is not incremental acceptance. Missing/empty/test-only reports and deliberate coverage reduction have negative tests.

The browser suite reuses the existing root/nested servers at 390/1440px, captures load/theme/navigation/search/tags/scroll/restoration, console and network errors, and records actual LayoutShift attribution. The session algorithm excludes recent input and starts a new session after a gap greater than one second or duration greater than five seconds. Normal pages are baseline-only until repeated native measurements support budgets. Deterministic reserved-space image/font/lazy/menu/comments/ad/consent/adblock fixtures use a 0.10 ceiling; explicit large shifts must make the same gate fail. FontFace uses an installed local font; no external-font-network result is implied. Lab CLS is not field p75 CLS.

Optional AdSense/GA4/Consent/DKMA/Giscus fixtures use mocks only. Disabled actual product pages must make zero related requests. Mock fixtures check consent, repeated initialization/pageviews, reserved ad/comment geometry and readable articles with blocked requests. They do not implement or claim acceptance of future modules #90–#93, or a live Giscus integration.

LHCI records three real measurements per URL, HTML and machine-readable JSON, CLS/LCP and complete resource/third-party audits. Baseline assertions are advisory until observed. A separate severe-shift page must fail the CLS assertion with nonzero exit; missing reports or collection errors cannot count as that expected failure.

Required attachments upload in normal fatal stages, followed by deletion of the local archive, native download and checksum comparison. A 14-day TTL is explicit. `failStages` retains failure diagnostics; `endStages` cleanup is supplementary because its failure alone does not fail CNB's parent pipeline. External post-container download remains a separate acceptance check. Source SHA, target SHA, merge SHA, Site digest, runtime and timings accompany evidence.
