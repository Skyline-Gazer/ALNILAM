## Native execution and authority

Actual isolated private repository: [KoolingMachine/ads-cnb-acceptance-20261027](https://cnb.cool/KoolingMachine/ads-cnb-acceptance-20261027). The current browser is authenticated as pony-gazing. Source checkout, native PR, branch protection, scanner/review execution and artifact download must each be read back independently. A GitHub green check is not a CNB result.

`pull_request` already includes source updates. SCA publication uses the trusted `pull_request.target` event, `scanMode: diff`, supported `format` and `publish: true`. The official code-review plugin documents ordinary PR events separately; it writes the actual `status/issues` schema, and critical findings can coexist with exit zero. There is one deterministic severity gate. It loads verifier code from the trusted target, rejects unknown/missing findings and source/target movement, and verifies the evaluated merge checkout. Native protection must prevent a PR from replacing its own authoritative pipeline; source code alone cannot prove that protection. Fork PRs fail closed pending a trusted API adapter. No PR-authored warning exception is accepted.

All container references in `.cnb.yml` use observed immutable registry digests. The Playwright manifest list includes amd64 and arm64; the runner explicitly selects amd64. Registry availability is not proof of a CNB pull/launch. Image source, manifest and runtime are recorded separately.

The browser suite reuses the existing root/nested servers at 390/1440px, captures load/theme/navigation/search/tags/scroll/restoration, console and network errors, and records actual LayoutShift attribution.
